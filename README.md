## 🚀 Projects I've Built (&amp; Still Building)

| # | Project | What it does | Tech |
|:-:|---------|--------------|------|
| ∞ | **STILL BUILDING** | Same passion, same thrust. | — |
| 4 | [**VoiceOps**](https://github.com/Eng-Hu-snain-Ali/Voiceops-Main) | Turns recorded or uploaded meeting and sales-call audio into a speaker-labeled transcript, summary, sentiment, action items, risks, decisions, and a draft follow-up email. | `Node.js 18+` `JavaScript` `React` `Speechmatics` `LLM API` |
| 3 | [**Failsim-AI**](https://github.com/Eng-Hu-snain-Ali/Failsim-AI) | Helps robotics teams discover why simulated robots fail (e.g. a gripper not holding an object) by running physics-based tests across robot and object conditions, then summarizing likely causes and possible fixes. | `Python` `PyBullet` `NumPy` `FastAPI` `React` `Vite` `Tailwind` `Gemini` |
| 2 | [**OutbreakAI**](https://github.com/Eng-Hu-snain-Ali/OutbreakAI) | Decision-support prototype: records disease activity by region, assigns a risk level, tracks case trends, and suggests responses like preparing hospital overflow capacity or running vaccination drives. | `Python` `Flask` `SQLAlchemy` `SQLite / PostgreSQL` `OpenWeatherMap` |
| 1 | [**Bus-Seat-Reservation-System**](https://github.com/Eng-Hu-snain-Ali/Bus-Seat-Reservation-System) | Front-end booking prototype: search bus trips, compare sample schedules, choose seats, and see a booking confirmation. | `HTML` `CSS` `Vanilla JavaScript` |

<details>
<summary><b>📌 Project notes &amp; known limitations (click to expand)</b></summary>
<br/>

- **VoiceOps** – The documented workflow is in the [README](https://github.com/Eng-Hu-snain-Ali/Voiceops-Main/blob/main/README.md). Uses Speechmatics for transcription and an OpenAI-compatible LLM API for structured extraction.
- **Failsim-AI** – Aims to reduce manual robot testing and make failure patterns easier to investigate. The [README](https://github.com/Eng-Hu-snain-Ali/Failsim-AI/blob/main/FailSim-AI-main/README.md) describes deployment on a Vultr VM.
- **OutbreakAI** – ⚠️ The live risk score is rule-based. The included ML model artifacts are not used in the API's risk decisions, and it is not a validated outbreak-prediction system. See [known limitations](https://github.com/Eng-Hu-snain-Ali/OutbreakAI/blob/main/README.md#known-limitations).
- **Bus-Seat-Reservation-System** – ⚠️ Schedules and seat availability are hard-coded and the flow is simulated in the browser. Seats stay booked only for the current page session. There is no backend or database. See the [booking code](https://github.com/Eng-Hu-snain-Ali/Bus-Seat-Reservation-System/blob/main/Bus%20go/script.js).
